# Art

Animations in the Divoom 16x16 format. Show one by name:

```sh
divoom-ditoo-pro-controller art list
divoom-ditoo-pro-controller art show fire
divoom-ditoo-pro-controller art show pixel_body_roll
```

Previews: https://justinwlin.github.io/divoom-ditoo-pro-controller/

- `fire`, `rain`, `heart`, `plasma`, `equalizer`, `spinner`, `checkmark`, `starfield`, `bounce`, `sunrise`: original
  animations, CC0.
- `pixel*`: Pixel, a calico cat. Face and full-body animations.

Add your own `.divoom16`, `.gif` or `.png` files to this folder, or point `--art DIR` or `DITOO_ART` at a different one.

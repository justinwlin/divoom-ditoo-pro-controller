# Soundpack for the Ditoo Pro SD card

A set of 257 short sounds for the Ditoo Pro microSD slot, and a script that plays one sound by name over BLE.
It needs no audio pairing and no custom firmware. The script runs on macOS.

Use it to give a program a voice: a build tool, an AI agent, or a timer can say "Your build is finished" or
"Timer, 25 minutes left" through the speaker.

## Contents

| Path | Content |
| --- | --- |
| `card/` | 257 MP3 files, `0000.mp3` to `0256.mp3`. Copy them to the card. |
| `manifest.json` | Track ID, name, category, text and length of each sound. |
| `tools/ditoo_play.py` | Plays sounds by name over BLE. |
| `tools/build_pack.py` | Builds `card/` and `manifest.json` from the source sounds. |
| `tools/make_batch.py` | Makes the voice files with ElevenLabs (needs `ELEVEN_API_KEY`). |
| `tools/make_jingles.py` | Makes the jingles with a small synthesizer. |
| `tools/jessica_lines.tsv` | Name and text of each voice file. |

| Category | Count | Examples |
| --- | --- | --- |
| jingle | 4 | done, message, error, good night |
| event | 25 | "Your build is finished.", "Some tests failed.", "I need your input." |
| personality | 12 | "On it.", "Nice!", "Hmm, let me think." |
| number | 65 | 0 to 59, 60, 70, 80, 90, 100 |
| word | 32 | timer, minutes, hours, percent, A M, P M, today, tomorrow |
| weekday, month, ordinal | 50 | Monday, January, "the first" to "the thirty-first" |
| weather | 18 | degrees, sunny, rainy, "with a high of" |
| noun | 22 | message(s), agent(s), task(s), pull request(s) |
| connector | 27 | "You have", "There are", new, remaining, done, failed |
| ambient | 2 | rain loop, cafe loop |

## Install

1. Format a microSD card as FAT32 with an MBR partition table. A new card usually has this format.
2. Copy the files in `card/` to the top folder of the card, in name order. Keep other audio files off the card.
3. On macOS, run `dot_clean -m /Volumes/CARD` to remove `._` files.
4. Put the card in the Ditoo. The Ditoo starts playback by itself. Stop it with `ditoo_play.py --stop`.

## Play

```sh
cd soundpack/tools
uv run --with bleak ditoo_play.py --list
uv run --with bleak ditoo_play.py j_done e01_build_finished
uv run --with bleak ditoo_play.py w_timer n25 w_minutes w_left
uv run --with bleak ditoo_play.py --loop a_rain
uv run --with bleak ditoo_play.py --stop
```

## How it works

The Ditoo gives each audio file on the card a track ID. On the tested device, the IDs started at 0 and followed
the file name order. The script uses four stock commands over the BLE link:

| Opcode | Use |
| --- | --- |
| `0xb9` + mode | Play mode. 1 = all tracks in order, 2 = repeat one track, 3 = random. |
| `0x11` + ID (u16 LE) | Select a track. Playback starts immediately. |
| `0x0a` + `00` | Pause. |
| `0xb4` | Status: elapsed seconds, length, track ID (each u16 LE), play flag, volume, play mode. |

The firmware has no "play one track and stop" mode. The script sets mode 2, selects the track, waits for the
length from the manifest, then sends pause. Each one-shot file has 0.6 seconds of silence at the end, so the pause
lands in silence.

## Your own tracks

Put your own files after the pack on the card, as `0257.mp3` and up. List them in `manifest.local.json`, in the same
format as `manifest.json`. Git ignores that file.

## Limits

- Tested on one Ditoo Pro with stock firmware, from macOS, with a 6-file test card: select, pause, status and
  play modes. The 257-file card and `ditoo_play.py` in this form are not yet tested on hardware.
- A sequence of words has a short gap between the words, because each word is a separate track.
- Each script run needs 2 to 3 seconds to connect. A program that keeps the BLE connection open has no such delay.
- New sounds must go at the end of the card, or the IDs in the manifest change.
